# MineHelper

Статический русскоязычный портал для Minecraft Java и Bedrock. Работает без сервера, аккаунта, платных API и сборщика. Избранное, тема и история хранятся в `localStorage` браузера.

### Персонализация

В «Настройки → Внешний вид» доступны восемь тем с превью и моментальным переключением, размер интерфейса и текста, скругления, плотность карточек, ширина контента, акцентные пресеты и собственный HEX-цвет, стиль карточек и компактное меню. Раздел анимаций включает эффекты нажатия, наведения и появления поверхностей, скорость, интенсивность, свечение и предпросмотр. Контрастный цвет текста подбирается относительно текущей светлой/тёмной поверхности. Настройки валидируются при чтении из `localStorage`, сохраняются без перезагрузки, а сброс возвращает стандартное оформление. Системная тема отслеживает `prefers-color-scheme`; системное сокращение движения отключает анимации.

## Запуск локально

Откройте `index.html` в браузере или запустите любой локальный статический сервер из каталога проекта, например `python -m http.server 8000`. Приложение использует hash-навигацию (`#enchants`, `#coordinates`), поэтому прямые ссылки не требуют серверного fallback.

## Публикация на GitHub Pages

1. Создайте GitHub-репозиторий и загрузите в его корень все файлы и каталоги из этой папки: `index.html`, `styles.css`, `app.js`, `core.js`, `data.js` и `README.md` (папку `tests` можно также сохранить в репозитории для локальных проверок).
2. На GitHub откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` (или вашу рабочую ветку) и каталог `/(root)`.
4. Сохраните. GitHub Pages опубликует сайт по адресу, который покажет сам репозиторий.

Файлы подключаются относительными путями (`./styles.css`, `./data.js`, `./core.js`, `./app.js`), поэтому работают и в адресе проекта вида `https://username.github.io/repository/`. Внутренние страницы используют `#route`, что исключает 404 при прямой загрузке подстраницы.

## Что реализовано

- Главная, глобальный поиск с категориями, подсказкой клавиши `/`, выбор Java/Bedrock.
- Избранное с локальным сохранением, история просмотров, смена темы, очистка данных.
- Фильтруемые справочники зачарований, рецептов, зелий, предметов, мобов, структур, биомов, команд и гайдов; карточки открывают подробности.
- Подбор чар по предмету и назначению, с редакционными оговорками, несовместимостями, копированием и сохранением сборки.
- Перевод координат, расстояние между точками, расчёт ингредиентов, топлива, опыта, количества блоков и текстовый генератор `/tp`.
- Чек-лист экипировки для похода с копированием.

## Проверки и известные ограничения

Поиск в справочниках обновляет существующие строки и карточки, не пересоздавая поле ввода. Результаты глобального поиска обновляются отдельно от поля. Браузерный проход остаётся недоступен в текущей среде (`ERR_BLOCKED_BY_CLIENT`), поэтому физическая клавиатура, мобильная экранная клавиатура, касания и визуальная раскладка не подтверждены.

Первый релиз содержит выборочные справочные данные, а не полный дамп Minecraft Wiki. Дата среза, записанная в данных: **18 октября 2026**. Внешняя поисковая выдача по Minecraft Wiki работала частично: страницы `/w/Enchanting`, `/w/Brewing`, `/w/Nether` и `/w/Smelting` блокировались robots.txt. Доступные страницы Wiki использованы для проверки конфликтов зачарований, базовых рецептов зелий и значений топлива. Основной источник: [Minecraft Wiki](https://minecraft.wiki/); точечные использованные страницы — [Best enchantments guide](https://minecraft.wiki/w/Tutorial:Best_enchantments_guide), [Brewing](https://minecraft.wiki/w/Brewing), [Smelting](https://minecraft.wiki/w/Smelting). Wiki — общественная энциклопедия, не официальный источник Mojang; механики сверяйте с версией мира.

В справочниках не для каждого факта указана отдельная версия. Калькулятор чар не считает цену опыта/оптимальный порядок наковальни. Списки рецептов и предметов выборочные, а не полные. Калькулятор материалов использует отдельные структурированные записи для подтверждённых рецептов; неоднозначные рецепты и переплавка (например, стекло) прямо помечаются как неподдерживаемые, без выдуманных результатов. Вложенные рецепты пока не раскрываются рекурсивно. Калькулятор опыта считает целые уровни, без полоски прогресса текущего уровня. Координаты используют округление до ближайшего блока, но подбор портала игрой может дать смещение. Генератор команд выдаёт шаблон Java `/tp`; команды зависят от версии и прав. Топливо рассчитано для обычной печи при одном предмете на операцию. Сохранение локальное и не синхронизируется между браузерами/устройствами.

## Расширение базы

Игровые записи собраны в `data.js` отдельно от интерфейса. Добавляйте структурированные записи в соответствующий массив и используйте поле примечаний для ограничения редакции/версии. Рекомендации сборок находятся в `BUILD` внутри `app.js`. Не добавляйте точные механические значения без проверки по конкретной версии и надёжному источнику.

## Лицензии и товарные знаки

MineHelper не связан с Mojang Studios или Microsoft. Названия Minecraft используются только для описания совместимости. Сторонние изображения и копии чужих баз данных в проект не включены.

## Безопасность и надёжность

- Скрипты и стили локальные; внешняя загрузка Google Fonts удалена. В `index.html` задана Content Security Policy без внешних соединений, плагинов и динамических скриптов.
- Данные из `localStorage` ограничены по размеру, типу, числу записей и длине полей; неподходящие/повреждённые значения игнорируются. Ключи хранения версионированы (`*-v1`). Текстовые поля при вставке в HTML экранируются, вывод калькуляторов использует `textContent`.
- Добавлены локальные экспорт и импорт JSON (схема 1). Импорт ограничен 256 КБ, проверяет типы, enum-значения, строки и количество записей; перед заменой данных спрашивает подтверждение. Загруженный файл не исполняется.
- Внешние ссылки в проекте заданы разработчиком, открываются с `rel="noreferrer"`; ввод пользователя не становится URL для перехода. Секретов, телеметрии, аккаунтов и сетевых запросов сайт не использует.
- Проверка зависимостей не требуется: npm-пакеты и сторонние JavaScript-библиотеки отсутствуют.

Проведён только ограниченный статический осмотр безопасности, это не полный аудит. Автоматизированный браузерный тест ранее не прошёл: среда блокирует локальный адрес `127.0.0.1`; поэтому визуальные размеры и интерактивный импорт/экспорт вручную не подтверждены.

## Повторный аудит интерфейса (18 октября 2026)

Исправлены найденные неисправности: обработчики боковых переключателей Java/Bedrock и перехода в настройки; whitelist `#settings`; неверное закрытие модального окна при нажатии внутри; открытие карточек справочников по стабильному названию после фильтра/сортировки; фактическая сортировка по категории; блок угля в калькуляторе топлива; прежний вывод стаков для 500 блоков; перебор уровней опыта заменён формулой с ограничением ввода. Кнопки меню теперь поддерживают Escape, закрываются после перехода и обновляют `aria-expanded`.

Запуск автоматических проверок из корня проекта:

```sh
node tests/core.test.cjs
node tests/ui-smoke.cjs
```

Core-тесты проверяют формулы координат, расстояния, опыта, топлива, объёмов и материалов рецепта, включая несколько ингредиентов, партии крафта, стаки, остатки и неверный ввод. UI smoke-тесты проверяют подключение ресурсов, действия кнопок, маршруты, модальные детали, CSS-прокрутку, темы и параметры, сохранение палитры, анимационные варианты, а также то, что фильтр обновляет DOM-записи без вызова рендера страницы. Эти статические проверки не заменяют проверку клавиатурного ввода в браузере.

Node-зависимости не нужны. Браузерный движок в текущей среде не предоставил доступ к локальному сайту, поэтому размеры 320–1920 px, ориентации, скринридер, реальные клики, сохранение между перезагрузками, визуальный контраст и импорт/экспорт не проверены. Перед публичной публикацией нужно пройти эти сценарии в реальном браузере на телефоне и компьютере.
